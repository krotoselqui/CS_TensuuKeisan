# 生成結果の回帰検査

`Fixtures/` は Main 整理前のコミット `50eb05d` から作成した比較基準。
シード 0 / 12345、表示形式 0 / 1、各 20 問の 4 組を含む。

- `question.txt`、`answer.txt`、`answer_yaku.txt` は実際の Shift_JIS 出力。
- `console.txt` は UTF-8 のコンソール出力記録。タイトル、入力プロンプト、進捗の文字列、役別集計、終了文言を含む。
- 改行・空白・文字コードも比較するため `.gitattributes` でバイト列を保持する。
- 作成環境は Windows / .NET Framework `4.8.09221`。同じ .NET Framework 系列での互換性確認を目的とする。

手動作成用の `scripts/Capture-LegacyBaseline.ps1` は指定コミットのソースを一時ディレクトリへ取得し、`Program` の `Console` 参照だけをテスト用に置き換える。入力を供給し、カーソル座標と終了キーを模擬する。元の Main の抽選・生成・採点・ファイル出力は変更せずに実行した。既存の保存先は上書きしない。CI で比較基準を自動再生成してはならない。

`scripts/Test-Generation.ps1` は `.csproj` の登録ソースを読み、現在の `Program` と `ConsoleProgress` のコンソール参照のみを同様に置き換え、`GenerationChecks.cs` と一緒に別のテスト実行ファイルへコンパイルする。アプリのソースとビルド成果物は書き換えない。

検査内容:

- 実際の Main から生成した 3 ファイルのバイト列、およびコンソール出力の比較。
- 同一プロセス内でのシード・表示形式の切り替え、再実行時の集計初期化。
- `GenerateProblems` へ渡した進捗通知の回数と順番、借りた writer を閉じないこと。
- 出力失敗時の例外伝播と旧生成処理への一時的な乱数・表示設定の復元。
- 不正文字列・範囲外・整数オーバーフローの再入力と、受理境界。
- Main が所有するファイルの解放。2 個目のファイルが開けない場合も 1 個目を閉じる。

コンソールの実際の画面配置と物理的なキー入力は模擬しており、見た目の検証ではない。保存結果は以前の動作の記録であり、全ての役・符計算が正しいことを独立に証明するものでもない。実行成果物は表示された一時ディレクトリに残す。
